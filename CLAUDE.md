# Instruções para IA neste repositório

Antes de qualquer alteração, leia `docs/LEIA_PRIMEIRO_IA.md` (o que já foi feito, o que não pode
ser mexido e as pendências) e o topo de `docs/HISTORICO_ALTERACOES.md`.

Ao terminar, registre o que você fez em `docs/HISTORICO_ALTERACOES.md` e suba tudo para o GitHub
(commit, push e Pull Request). A documentação vai no mesmo PR da mudança.
